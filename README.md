# Editing the portfolio template

Open `index.html` in any code editor. Every place that needs your real information is either visible as a placeholder or marked by an HTML comment.

## Add your information

1. Your supplied name, email, phone number, location, study focus, and introduction have already been added.
2. Put your image in an `images` folder beside `index.html`, then replace the `portrait-frame` block with an `<img>` tag. Add CSS for the image as needed.
3. For each project, replace `Untitled project`, `Category · Year`, and the gray project visual. Duplicate a full `<article class="project-item">...</article>` block to add a project.
4. Change the text in the Approach section to a sentence that reflects your actual working style.

## Preview it

Double-click `index.html` to open it in a browser. For best results, edit with VS Code and install the **Live Server** extension, then choose **Open with Live Server**.

## Included behavior

- Responsive desktop and mobile layouts
- Mobile navigation menu
- Keyboard focus and skip-to-content link
- Scroll-reveal animation that respects reduced-motion settings
- Automatic footer year

No personal data, image files, social links, projects, or invented claims were added.
